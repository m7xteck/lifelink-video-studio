Dark by default for review work, with a paper light theme from the LifeLink brand. Type: Hanken Grotesk for the interface and a monospace face for timecodes only. Colour carries meaning: blue is running or yours, green is verified, amber needs a decision, red has failed. "Measured" and "Estimate" tags appear wherever a number could be mistaken for the other.
