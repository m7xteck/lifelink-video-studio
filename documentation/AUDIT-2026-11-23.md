## Partially implemented
- **Specialist subagents**: definitions exist in `.claude/agents/` but are NOT registered in this session (session started before the project existed). Tested only by giving their instructions to general-purpose agents. Registration must be verified in a new session opened on the repository.
- **Brand locking**: tokens are used everywhere (no hard-coded colours/fonts). But nothing prevents editing `brand/design-system.json`, the watermark is optional per manifest (not forced while NEUTRAL_TEST), and `isApprovedBrand` is unused.
- **Approval gate**: enforced in the status system and orchestrator, but `pipeline/render.ts` can be run directly on any lesson regardless of approval.
- **Creative memory**: files and structure exist; nothing is updated automatically (motion-library `usedIn` was hand-written; preferences/decisions are manual).
- **Revision workflow**: section-level re-render and versioning work. Mapping "fix 2:10–2:30" to scenes is done by the Director by hand; there is no helper tool, and no before/after comparison tool.
- **QA**: objective checks work. Creative review is not wired into `produce.ts`. Portrait renders aren't part of `produce.ts`.
- **Deliverables**: thumbnail is a video frame (not designed). The social plan is a simple list.
- **Storyboards**: `storyboard.md` image links break in Git (frames are gitignored).
