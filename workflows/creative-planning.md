# Creative planning guide (adaptive storytelling)
For each teaching section note: meaning · emotional weight · educational purpose · complexity · key takeaway · visual intensity (still / calm / active).
| Content | First-choice treatment | Notes |
|---|---|---|
| Section change | sectionTitle | Only at real teaching transitions |
| A principle worth remembering | kineticStatement | 1–3 lines, emphasise 1–2 words max |
| Emotional / reflective | quietReflection | Minimal text, let it breathe; may hold 8–15 s |
| Process, steps, framework | stepsDiagram | Nodes arrive as each step is named |
| Contrast (healthy vs unhealthy, etc.) | comparison | Preferred side focuses last |
| Relationship between two people/ideas | connectionMetaphor | Two whole forms; never merged/erased |
| Recap | takeaway | Points arrive as spoken |
Avoid: same scene type 3× in a row unless it's a deliberate series; illustrating every noun; constant motion; text that paraphrases into new claims.
Gaps in the library (e.g. timeline, cycle diagram, quote with attribution, chapter recap map, branded intro/outro) are added by the Motion Design Director and go through approval before becoming defaults.
